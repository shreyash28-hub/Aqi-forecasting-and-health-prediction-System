# Live models: winter test

Four 30-day test windows covering last winter (1 Nov 2025 to 28 Feb 2026), each trained only on the data before it (from Feb 2025), with the same models, settings and seasonal prior as the regular live evaluation. The regular evaluation's windows cover April to October, so this is the first test of the live models in the smog season. Generated by `scripts/winter_report.py`.

**Caveats.** With under a year of training data before last winter, the same-day-last-year baseline cannot run, so the naive comparison uses the last-value and same-weekday-last-week baselines. The seasonal prior's per-city scale needs 300 training days, so the November and December windows use the prior at full strength (scale 1.0), exactly as the live system would have then.
