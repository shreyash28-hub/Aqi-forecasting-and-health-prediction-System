# Live models: choosing with winter included

Each city's model is chosen by the lowest mean RMSE over its test windows and must beat the best naive forecast. Until now the live comparison used only the recent windows (spring to autumn); this run adds last winter's four windows (ending 2025-11-30, 2025-12-30, 2026-01-29, 2026-02-28). Both the model deployed now and the new winner are scored on the same windows below. RMSE is in AQI points (µg/m³ for PM2.5 and NO2). Generated by `scripts/selection_report.py`.
